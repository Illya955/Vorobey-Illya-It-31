Завдання 5. Свідома помилка прямого імпорту

Під час спроби виконати команду .mode csv у вкладці Execute SQL програма DB Browser видала помилку синтаксису near ".": syntax error.

Причина полягає в тому, що .mode csv та .import є спеціальними командами SQLite CLI, а не звичайними SQL-запитами.

Теоретично прямий імпорт у таблицю cars також має проблему: CSV-файл містить 5 колонок, тоді як таблиця має 6 колонок, включно з первинним ключем id.

Тому для правильного імпорту використовується проміжна таблиця без колонки id.

Примітка: повноцінну перевірку прямого імпорту на окремій копії бази не завершено.

Контрольні питання

1. Чому CSV-файл не містить колонку id?

Тому що SQLite автоматично створює унікальні ідентифікатори для нових записів. Якщо вручну додати довільні ID, вони можуть збігтися з уже наявними, що спричинить помилку первинного ключа.

2. Яка роль команди DROP TABLE?

Команда DROP TABLE видаляє проміжну таблицю після перенесення даних. Якщо залишити її та повторно виконати INSERT ... SELECT, старі записи можуть бути перенесені повторно.

3. Чим COUNT(*) кращий за візуальну перевірку?

COUNT(*) дозволяє точно визначити кількість записів у таблиці. Порівняння результатів до і після імпорту підтверджує, що додано саме 8 записів.
