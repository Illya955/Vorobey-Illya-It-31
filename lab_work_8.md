Варіант 5 

Завдання 1. 

Для фактової таблиці sales виконано запит:

SELECT
    COUNT(*) AS усі_продажі,
    COUNT(sale_date) AS продажі_з_датою
FROM sales;

Отримано:

усі_продажі = 10
продажі_з_датою = 10

Додаткова перевірка:

SELECT *
FROM sales
WHERE sale_date IS NULL;

Результат:

0 rows returned

Отже, у поточній базі даних немає записів, у яких sale_date дорівнює NULL.

Було також зроблено спробу навмисно встановити NULL:

UPDATE sales
SET sale_date = NULL
WHERE id = 3;

Але SQLite повернула помилку:

NOT NULL constraint failed: sales.sale_date

Це означає, що колонка sale_date має обмеження NOT NULL, тому значення NULL для неї заборонене.

Отже, у цій базі COUNT(*) і COUNT(sale_date) дають однаковий результат — 10, оскільки всі 10 записів мають заповнену дату продажу.

Завдання 2. 

Для числової колонки sale_price виконано:

SELECT
    SUM(sale_price) AS загальна_сума_продажів,
    AVG(sale_price) AS середня_ціна_продажу
FROM sales;

Результат:

загальна_сума_продажів = 7175000
середня_ціна_продажу = 717500

Отже:

загальна сума всіх продажів становить 7 175 000;

середня ціна одного проданого автомобіля становить 717 500.

Для дати продажу виконано:

SELECT

Результат:

найраніша_дата_продажу = 2026-08-01

Завдання 4. 

Для отримання загального звіту по таблиці sales виконано:

SELECT
    COUNT(*) AS кількість_продажів,
    SUM(sale_price) AS загальна_сума_продажів,
    AVG(sale_price) AS середня_ціна_продажу,
    MIN(sale_price) AS мінімальна_ціна_продажу,
    MAX(sale_price) AS максимальна_ціна_продажу

Результат:

кількість_продажів = 10
загальна_сума_продажів = 7175000
середня_ціна_продажу = 717500
мінімальна_ціна_продажу = 490000
максимальна_ціна_продажу = 950000

Завдання 5.

Для підрахунку статистики тільки для автомобілів марки Toyota виконано:

SELECT
    COUNT(*) AS кількість_продажів,
    SUM(sales.sale_price) AS сума_продажів,
    AVG(sales.sale_price) AS середня_ціна_продажу
FROM sales
INNER JOIN cars
    ON sales.car_id = cars.id
WHERE cars.brand = 'Toyota';


Результат:

кількість_продажів = 2
сума_продажів = 1435000
середня_ціна_продажу = 717500

Контрольні питання
1.COUNT(*) рахує всі рядки таблиці, незалежно від значень у колонках.

COUNT(колонка) рахує тільки ті рядки, у яких зазначена колонка не має значення NULL.

Тому, якщо в колонці є NULL, COUNT(колонка) буде меншим за COUNT(*).

COUNT(*) і COUNT(id) для первинного ключа практично завжди однакові, тому що первинний ключ не може містити NULL.

У моїй таблиці sales COUNT(*) = 10 і COUNT(sale_date) = 10, тому що sale_date має обмеження NOT NULL і всі 10 записів мають дату продажу.

2.Знаменник дорівнював би 4.

AVG() не враховує значення NULL. Тому якщо є 5 рядків, але тільки 4 з них містять числові значення, середнє обчислюється за цими 4 значеннями.

Тобто фактично:

AVG = сума 4 значень / 4

3.Якщо всі значення колонки дорівнюють NULL, функція SUM() поверне NULL.

Вона не поверне 0 і не спричинить помилку.

Причина полягає в тому, що немає жодного числового значення, яке можна було б підсумувати.
